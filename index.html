SnapDose – AI Diabetes Nutritionist

Partnered with Ryan Stoffel, Elijah Tabor, Micah Suk, and Millie Anderson  ·  California Baptist University  ·  Jan 2026 – May 2026
SnapDose is a mobile application that helps diabetes patients count carbs instantly. Users snap a photo of their meal and get an AI-powered carbohydrate estimate in seconds instead of spending 5–10 minutes on manual calculation. The app tracks meal history, shows confidence for each estimate, identifies food items in photos, and monitors weekly trends. By making carb counting fast and easy, SnapDose helps patients make better food choices and manage their blood sugar more effectively. SnapDose runs on a serverless Google Cloud Platform architecture. The React Native frontend uses Firebase Authentication and Firestore, with security rules keeping each user's data private. When a user uploads a meal photo, Firebase Storage triggers a Google Cloud Function that sends the image to the Google Gemini 3.1 Pro API with specialized nutrition prompts; Gemini returns carb estimates, confidence levels, detected foods, and notes, which are saved to Firestore with timestamps. The app caches data locally through Firestore's offline persistence. A Spring Boot REST API bridges the app to a simulated physical insulin pump built on a Tab5 microcontroller: when a user logs carbs and requests an insulin dose, the request is sent securely through Firebase Authentication to the Spring Boot API, which relays it to the Tab5 device. The Tab5 pump polls for pending bolus requests, delivers insulin, reports confirmation to Firestore, and maintains heartbeat communication. SnapDose also integrates the Dexcom API to pull real-time continuous glucose monitoring data, so users can view blood sugar alongside meal tracking and insulin dosing in one unified dashboard. The whole system scales automatically, with all user data stored securely and controlled by the user.

Bogey Busters – Golf Tracking App

Partnered with Ryan Stoffel  ·  Sept 2025 – Present Bogey Busters is a golf tracking mobile app built with Flutter/Dart and Firebase that uses GPS positioning and the Google Maps SDK to help golfers track their shots, distances, and rounds on actual golf courses with real-time location data. The app integrates OpenStreetMap's Overpass API to fetch detailed course layouts and uses Firestore for real-time data syncing, SharedPreferences for local game state persistence, and Firebase Storage for media management. It includes social features like friend requests, likes, and comments through Firestore streams, with Firebase Authentication handling user management.
  • Flutter mobile app with a Firebase backend handling user authentication, profile management, and real-time data sync across 40+ database documents.
  • OpenStreetMap Overpass API integration that fetches course data – hole layouts, tee box coordinates, and green locations – with automatic caching to reduce API calls.
  • Google Maps SDK with custom markers and polylines to track shot distances, calculate bearing angles, and display real-time GPS positioning during a round.
  • Round persistence system using SharedPreferences that saves game state locally, letting users resume an incomplete round after an app restart.
  • Social feed with friend requests, likes, and comments powered by Firestore real-time streams and Firebase Storage for profile pictures.
